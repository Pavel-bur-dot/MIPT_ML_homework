
# Домашнее задание №2

Репозиторий содержит код для обучения, валидации и сравнения различных моделей машинного обучения (включая случайный лес, градиентный бустинг и стекинг) для предсказания оценки диалога.

## Структура проекта

Вся логика работы с моделями разделена по файлам для удобства командной работы:

1. **Ноутбуки с обучением и тестированием:**
   Каждая модель (или группа моделей) обучалась и тестировалась в отдельном Jupyter-ноутбуке.
   - `01_random_forest.ipynb` — Random Forest (базовая модель и подбор параметров).
   - `02_gradient_boosting.ipynb` — Градиентный бустинг (sklearn и CatBoost).
   - `hw2_stacking.ipynb` — Стэкинг базовых моделей и анализ утечек.

2. **Итоговый отчет:**
   Главный результат работы, итоговые метрики, графики, матрицы ошибок и финальное сравнение всех моделей собраны в файле **`solution.ipynb`**.

3. **Сохраненные модели:**
   Все обученные и готовые к инференсу модели сохранены в файле **`artifacts`** (в формате `.joblib`).
